# hide-ebay-listing-docs

Public user guide for the [Hide eBay Listing](https://github.com/hvesoftware/hide-ebay-listing-firefox)
browser extension, published via GitHub Pages.

- Live site: https://hvesoftware.github.io/hide-ebay-listing-docs/
- Source for the extension itself lives in the private
  `hide-ebay-listing-firefox` repo — this repo holds only the public-facing
  help page (`index.html`) and its screenshots (`images/`), so the extension's
  source never needs to be made public to host this.

To update the guide, edit `index.html` (and add/replace files under
`images/`), commit, and push to `main` — Pages redeploys automatically.
